Cubo

Tienda virtual especializada en productos de tecnología y gadgets. Catálogo por categorías, fichas de producto con especificaciones y valoraciones, y un proceso de compra completo con datos de envío y métodos de pago. Incluye una integración con la API de Amazon que importa cualquier producto a partir de su enlace.

Importar productos desde Amazon

Para ampliar el catálogo sin carga manual, Cubo integra la API de Amazon. El usuario pega el enlace de un producto en el buscador ("Buscar o pegar link de Amazon…") o en el bloque "¿Viste un producto en Amazon?", y la tienda trae sus datos y arma la ficha lista para vender.

  1. 1
    Pegar el enlace

    El usuario pega la URL del producto de Amazon desde el buscador de la cabecera o desde la sección dedicada del inicio.

  2. 2
    Extracción del ASIN

    Se detecta el identificador único del producto (ASIN) a partir de la URL, admitiendo los distintos formatos de enlace de Amazon.

  3. 3
    Consulta a la API

    Se piden los datos del producto por su ASIN. Fuente principal: Rainforest API (Amazon.com). Respaldo automático con ScraperAPI si la primera no responde.

  4. 4
    Normalización y caché

    La respuesta se transforma al formato del catálogo de Cubo y se guarda en caché local por ASIN, para no repetir llamadas ante la misma consulta.

  5. 5
    Ficha lista y checkout

    Se genera la ficha completa con enlace de vuelta al producto original en Amazon, y queda disponible para añadir al carrito y pasar por el checkout.

Título y categoríaNombre completo del producto y su ruta de categoría.

EspecificacionesFicha técnica y ASIN de referencia.
Imágenes y variantesGalería del producto y opciones como talla, estilo o color.

Nota técnica — La extracción se resuelve desde el navegador con caché local por ASIN; Rainforest API como fuente primaria y ScraperAPI como respaldo, con reintentos vía proxy para sortear CORS. Cada ficha importada mantiene el enlace directo a su página original en Amazon.
